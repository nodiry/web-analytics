# traffic

Bun HTTP beacon receiver for Glasscube Analytics.

See root README.md for full documentation.

## Quick start
```bash
bun install
bun run dev
```

## Environment variables
- `DB` — MongoDB connection string
- `PORT` — Server port (default 3001)

## Requirements
Place `geoip.mmdb` (MaxMind GeoLite2) in this directory.
